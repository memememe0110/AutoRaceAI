## v3.3 変更点

- レース名称を重複判定から除外しました。
- 「一般戦」と「7R」など表記が異なっても、同一選手・同一日・同一開催場で、着順、ハンデ、試走T、競走T、STが一致する場合は同じ走行結果として扱います。
- 走路が「湿」「斑」など登録元によって揺れていても、その他の走行結果が一致する場合は重複として整理します。
- 新規登録時は同じ走行結果を自動でスキップします。
- DB確認画面の「氏名・同一レースの重複をまとめて整理」で、既存の重複も一括削除できます。
- レース番号と一般戦名が重複した場合、表示には具体的な `7R` などのレース番号を優先します。
