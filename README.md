# AutoRaceAI スマホ本予測 Ver27 混合展開修正

Ver26を基に、熱走路で起こる「前残り＋実力車の追い込み」の混合展開を改善しました。

## 主な変更

- 最前ハンデ車の裏付けが弱い場合、10m後ろの有力車を早期先頭候補へ追加
- 10m候補は無条件の逃げ車ではなく、ST安定・実戦変換・近況・連対実績で判定
- 熱走路でも捌きと実戦変換力が高い後方車は追い込み制限を最大55%緩和
- 選手別条件適性の少数データ上限を縮小
  - 4～7件: ±0.3点
  - 8～14件: ±0.7点
  - 15～24件: ±1.2点
  - 25件以上: ±1.8点
- 熱走路適性の単独重みを1.20から0.95へ緩和し、全体熱補正との二重計上を抑制
- Ver26のオッズ比較、データ件数表示、欠車切替、結果保持などは継承

## 狙い

0m車だけを前残り候補にせず、0mを早めに交わした10m車が逃げ役になる展開を表現します。同時に、熱走路でも能力と捌きの裏付けがある40m勢を一律に沈めません。
