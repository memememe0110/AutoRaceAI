# AutoRaceAI Ver18.1 公式出走表対応

GitHubでフォルダを作る必要はありません。ZIP内のファイルをリポジトリの一番上へアップロードしてください。

## 対応した貼り付け形式

- `6R`
- `2026年7月21日(火)`
- `20:05発走 3100m 7車 6周`
- `湿走路 /34℃`
- `気温：30℃`
- `湿度：88%`
- 車番と選手名から始まる公式出走表の選手ブロック

選手ごとに次を読み取ります。

- 車番
- 選手名
- ハンデ
- ST
- 試走T
- 現ランク
- 車名
- 平均試走T
- 平均競走T
- 最高競走T
- 湿2連対率
- 湿3連対率
