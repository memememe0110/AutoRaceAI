# AutoRaceAI スマホ本予測 v4.0

## 主な変更
- 現在データベース `autorace_players 6.sqlite3` を同梱
- 5要素から10要素へ拡張
  - 試走、ST、ハンデ、近況、走路適性
  - 前残り、追い込み、周回安定、コース適性、相手耐性
- 選手ごとの「主な評価理由」を表示
- 結果登録後、10要素の調整前・調整後・変化量・相関を表示
- 1レースの自動変更幅を±0.003以内に制限
- 三連単は着順まで完全一致した場合のみ的中
- 同じレースに調整後重みを当てた値は診断専用で、正式成績には加算しない

## 注意
過去データが少ない新要素は0.5（中立）として扱います。登録結果が増えるほど、前残り・追い込みなどの差が出やすくなります。
