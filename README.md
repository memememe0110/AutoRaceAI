# AutoRaceAI スマホ本予測 v4.1

## 主な変更

- 10要素評価を継続
- 登録済みの全結果を重み調整に利用
- 直近20レースを中心に、最新ほど指数減衰 `0.90 ** 経過レース数` で強く反映
- 20レースより古い結果も累積傾向として20%残す
- 同一レース判定は `開催日 + 開催場 + レース番号`
- レース名称（一般戦、予選、開催名称など）は重複判定に使用しない
- 同一レースを再登録した場合、結果・選手履歴・重みを更新しない
- 着順なし、欠車、競走中止、落車、反則、不成立、失格は順位分析から除外
- 除外行も試走、ST、走路条件など利用可能な履歴は保存
- 有効着順が3名未満の場合は重み調整しない
- 三連単は1着→2着→3着の順番まで完全一致した場合のみ的中
- 「最後の結果登録を取り消す」を追加
  - 結果、周回、払戻、予測比較、重み調整、自動追加選手履歴を取り消し
  - 予測スナップショットは再登録用に残す

## DB
