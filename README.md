# AutoRaceAI Personal Streamlit版

## ローカル起動
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud
1. このフォルダ一式をGitHubの非公開リポジトリへアップロードします。
2. Streamlit Community Cloudでリポジトリと `app.py` を選択します。
3. 公開URLをスマホのホーム画面へ追加します。

## DBについて
無料ホスティングでは再起動時にローカルファイルが消える場合があります。DB管理タブからSQLiteをこまめにバックアップしてください。
