# AutoRaceAI スマホ本予測 v3.4

追加機能:
- 公式結果ページ全文の解析・登録
- 同一レースは日付＋開催場＋レース番号で上書きし、名称違いによる重複を防止
- 予測時に予測順位・1着率・3着内率をDB保存
- 結果登録時に平均順位誤差、1着的中、予測TOP3一致数、選手別順位誤差を解析
- GitHub DB永続保存対応

使い方:
1. 予測タブで通常どおり予測する
2. レース確定後、「結果登録・解析」へ公式結果ページを貼る
3. 解析内容を確認してDB登録する

少数レースで急激に補正すると過学習しやすいため、v3.4は誤差を蓄積・可視化し、補正判断の土台を作る方式です。
