# AutoRaceAI スマホ本予測 v3.5

## 追加内容

- 公式結果ページの縦型全文貼り付けに対応
- 開催日、開催場、レース番号、走路状態、走路温度、気温、湿度を解析
- 着順、車番、選手名、所属、ハンデ、試走T、競走T、ST、人気を登録
- 1周目から6周目、ゴール線までのグランドノートを保存
- 単勝、複勝、2連複、2連単、ワイド、3連複、3連単の払戻金を保存
- 保存済み予測との順位誤差、1着的中、TOP3一致を解析
- 1周目先頭、ゴール先頭、先頭交代回数、最大順位上昇を展開解析
- 同じ開催日・開催場・レース番号は上書きし、レース名称違いによる重複を防止

## 使い方

1. 「結果登録・解析」タブを開く
2. 公式結果ページをレース番号から払戻金まで全文コピーして貼り付ける
3. 「結果を解析」を押して内容を確認する
4. 「DBへ登録して予測差・展開を解析」を押す

Streamlit CloudでDBを保持する場合は、従来どおりGitHub Secretsを設定してください。
