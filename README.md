# AutoRaceAI スマホ本予測 v3.1

## 追加内容
- 6周詳細シミュレーション結果から、2連単（2車単）・2連複（2車複）・3連複・3連単を集計
- すべての券種確率を `%` 表示
- 各組み合わせのシミュレーション的中回数も表示
- 今回の走路状態・走路温度・気温・湿度と、予測への反映状況を画面表示

## 環境条件の扱い
- 走路状態: 過去履歴の走路適合重みに直接使用
- 走路温度: 6周シミュレーションの展開確率・変動幅に直接使用
- 気温・湿度: 読み取り、DB保存、類似レース検索には使用。予測タイムへの独立した直接補正は未実装
