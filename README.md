# AutoRaceAI スマホ本予測 Ver20

## Ver20の変更点
- 欠車判定を車番ごとの選手ブロック内だけで行うよう修正
- 後続選手の「欠車」を前の選手へ誤割当する不具合を修正
- 予測前に「欠車・出走取消として除外する車番」を手動選択可能
- 自動判定が間違っている場合は選択を外すだけで出走へ戻せます
- 自動判定されていない欠車も車番を選んで除外できます

## 使用方法
1. 公式出走表を全文貼り付けます。
2. 貼り付け欄の下に表示される欠車車番を確認します。
3. 誤判定なら選択を外し、欠車を追加する場合は車番を選択します。
4. 予測ボタンを押します。

# AutoRaceAI スマホ本予測 Ver17

## Ver17の主な変更
- 欠車・出走取消・不出走を自動検出し、順位・確率・買い目から完全除外
- 欠車を「勝率0%」ではなく「レースに存在しない選手」として処理
- 5～8車に応じて三連単組み合わせ数を自動変更
- スマホ縦型出走表の「ハンデ10m/ST0.17 3.48」形式を解析
- 当日試走、ST、ハンデ、実戦能力、終盤、当日状態から予測競走タイムを算出
- 予測タイム差が明確なレースだけ確率差を広げる
- 混戦では無理に確率を尖らせない
- 「混戦・やや本命・本命明確」を表示
- v4.1の直近重視、重複防止、欠損着順除外、Undoを維持

## 今回の欠車例
1番が欠車の場合、1番は解析対象から除外されます。
残った車が5車なら、三連単は 5×4×3 = 60通りです。

## Ver17.1 追加修正
- 古いSQLite DBの adjustment_log に不足列があっても、既存データを残したまま自動追加
- 予測入力・結果入力・選手入力のリセットボタンを追加
- 登録情報確認から、過去の登録結果・着順・周回・払戻・解析内容を再閲覧可能
- リセット操作は入力欄だけを消し、DB登録データには触れません


## Ver18 精度改善（継承）
- 重大修正: 結果登録で学習した10項目重みを、本番予測でも実際に適用
- 旧版で残っていた5項目学習適用との不整合を解消
- 有効な結果登録が30レース未満の間は初期値へ縮約し、少数レースへの過学習を抑制
- 添付された最新DBを同梱


## Ver19 追加改善

- 10m換算秒の初期値を `0.018` から `0.012` に変更
- 同ハンデ帯の外枠最大減点を4.5点から3.0点へ緩和
- S/A/B級、審査ポイント、後方追上げ指数、レース巧者指数、勝ち切り指数を使い、追い込み能力の高い選手ほど外枠減点を緩和
- 強い選手でも外枠リスクを完全にはゼロにせず、最低限の減点は維持
- 既存DBと10項目学習機能はそのまま継承
