# AutoRaceAI スマホ本予測 v3.8

## 今回の変更

- 終わらない原因になり得る逐次追抜き入替ループを予測経路から外しました。
- 高速ベクトル型の6周イベントシミュレーションへ切り替えました。
- 各試行で、ST反応、1周目の伸び、隊列形成、中盤の突破機会、最終周の差しを生成します。
- 7車・8車を自動判定し、「未登録8」は予測対象に含めません。
- 三連単、三連複、2車単、2車複の確率を同じ試行結果から集計します。
- 結果登録時の選手履歴更新、風走路、`-m`→0m対応を維持しています。

## 調整の考え方

Ver15.2由来の選手評価や総合点は維持し、展開シミュレーション部分だけを変更しています。
従来のように隣接車を何度も入れ替える処理はせず、試行ごとのスコアを行列計算して順位化するため、同ハンデ車が多い優勝戦でも処理時間が発散しません。

## 実行

```bash
pip install -r requirements.txt
streamlit run app.py
```
