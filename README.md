# AutoRaceAI スマホ本予測 Ver21

## 今回の修正

### 1. リセットが効かない問題
Streamlitの入力ウィジェットが固定キーを再利用していたため、スマホブラウザ側に残った値が再描画時に復元される場合がありました。

Ver21ではリセットするたびに入力欄の世代番号を更新し、新しいウィジェットとして作り直します。

対象:
- 予測入力
- 結果入力
- 選手情報入力
- 欠車・出走取消の手動選択

### 2. 結果解析がすぐ非表示になる問題
DB登録後の解析結果が、登録ボタンを押した実行回だけに表示されていました。

Ver21では以下をセッションへ保存し、画面が再描画されても再表示します。
- 平均順位誤差
- 1着的中
- TOP3一致数
- 予測と実結果の比較
- 三連単の完全一致判定
- 学習重みの変更内容

結果入力をリセットすると、保持している直前の解析結果も消去されます。

## 起動
```bash
pip install -r requirements.txt
streamlit run app.py
```
