# AutoRaceAI スマホ本予測 Ver17

## Ver17の主な変更
- 欠車・出走取消・不出走を自動検出し、順位・確率・買い目から完全除外
- 欠車を「勝率0%」ではなく「レースに存在しない選手」として処理
- 5～8車に応じて三連単組み合わせ数を自動変更
- スマホ縦型出走表の「ハンデ10m/ST0.17 3.48」形式を解析
- 当日試走、ST、ハンデ、実戦能力、終盤、当日状態から予測競走タイムを算出
- 予測タイム差が明確なレースだけ確率差を広げる
- 混戦では無理に確率を尖らせない
- 「混戦・やや本命・本命明確」を表示
- v4.1の直近重視、重複防止、欠損着順除外、Undoを維持

## 今回の欠車例
1番が欠車の場合、1番は解析対象から除外されます。
残った車が5車なら、三連単は 5×4×3 = 60通りです。
